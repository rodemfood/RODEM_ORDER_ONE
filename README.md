# RODEM ORDER ONE v3.1 AUTO RECOVERY

## 핵심 수정
- 휴대폰에 고객 토큰뿐 아니라 업체명, 수령인, 연락처, 우편번호, 전체 주소를 함께 저장합니다.
- Render 무료 서버의 임시 SQLite가 재시작으로 초기화되어도 동일 브라우저에서는 고객정보를 자동 재등록하고 바로 주문 화면을 엽니다.
- 쿠키가 사라져도 로컬 프로필로 자동 복구합니다.
- 기존 고객정보 불러오기 기능은 최종 예비 수단으로 유지합니다.
- 고객 모바일 주문, 직원 PC 관리, 로젠 송장, 거래처 엑셀 자동변환 기능을 유지합니다.

## 중요
- 무료 Render의 검은색 `SERVICE WAKING UP` 화면은 무료 서버 절전 정책이라 코드로 제거할 수 없습니다.
- 이 버전은 동일 휴대폰/동일 카카오톡 내장 브라우저에서 고객정보 재입력 문제를 크게 줄입니다.
- 카카오톡 앱 데이터 삭제, 다른 브라우저 사용, 휴대폰 교체 시에는 고객정보 복구 입력이 필요할 수 있습니다.
- 주문 이력까지 영구 보존하려면 PostgreSQL/Supabase 같은 영구 DB 연결이 필요합니다.
